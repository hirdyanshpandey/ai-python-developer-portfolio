Privacy

The tool code processes inputs in your browser and does not store inputs in local storage or send tool payloads to a server. Hosting may retain normal access logs. No analytics or advertising scripts are included in this version.

Scope

These are practical helpers, not replacements for a database schema, complete API specification or production configuration review.
