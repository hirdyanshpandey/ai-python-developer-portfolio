Generate Pydantic v2 models from a JSON sample

Paste a JSON object and generate nested BaseModel classes. Types are inferred from the sample, so a field missing from a sample cannot be inferred. Null is emitted as Any with a None default; validate and refine generated models before production use.

Will this infer every possible API response?

No. A sample is a starting point, not a complete API contract. Mixed arrays use Any when their element types disagree.
