ENV Key Comparer

Compare environment variable names without displaying their secret values.

Find missing ENV keys between deployments

Paste the two environment files. Only variable names are compared; values are neither shown in results nor compared. Supports comments, export prefixes and common KEY=value lines. Parsing here targets one-line assignments.

Can I compare secrets safely?

Prefer pasting key names with placeholder values. Processing happens locally, but you should still avoid copying production secrets into websites.
