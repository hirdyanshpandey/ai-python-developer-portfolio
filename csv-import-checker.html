How the CSV checker works

Paste comma-separated CSV with a header row. The checker supports quoted commas, escaped quotes and line breaks within quoted fields. It reports duplicate or empty header names, inconsistent column counts, and whitespace-only cells. It checks file structure; it does not validate your database schema.

Can it check large CSV files?

This first version limits input to 2 MB to keep the page responsive. Export a representative sample for larger files.
